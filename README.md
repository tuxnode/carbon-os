# Carbon OS 

[简体中文](./README-zh.md)

CarbonOS is a build-from-scratch, independent, memory-safe, and terminal-first immutable Linux distribution.

Engineered for developers who demand sub-second responsiveness, a keyboard-driven workflow, and uncompromising system predictability. CarbonOS sheds legacy GNU bloated toolchains in favor of an LLVM/Clang + Musl libc base and embraces Rust for its core userland utilities.
